## Development

When starting the dev server, use background mode:

```sh
astro dev --background
```

Manage it with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Pitch deck

Work on the investor pitch deck (`src/pages/pitch-investor-rm-2026x.astro` and related pitch copy or CSS) should **not** include updates to `README.md` unless the user explicitly asks for README changes.
