# roomieVerse Labs Ecosystem

Repository chính thức chứa landing page giới thiệu hệ sinh thái **roomieVerse Labs** (bao gồm Roomio, roomieVerse và Roomibase) cùng với các tài liệu nội bộ liên quan.

Dự án được xây dựng bằng **Astro framework** với giao diện tối giản (minimalism), tối ưu hóa tốc độ tải trang, sử dụng phong cách thiết kế hiện đại với các hiệu ứng cuộn mượt mà (scroll reveal animations). Hỗ trợ đa ngôn ngữ (Tiếng Việt, Tiếng Anh, Tiếng Ả Rập).

## 🌍 Các sản phẩm trong hệ sinh thái

- **Roomio:** Nền tảng vận hành & quản lý phòng cho thuê (chốt điện nước, thu tiền, gửi bill tự động qua Bot).
- **roomieVerse:** Nền tảng tìm kiếm phòng share - tìm bạn ở ghép trực tiếp không qua trung gian.
- **Roomibase:** (Sắp ra mắt) Nền tảng tìm phòng, tìm nhà cho thuê nguyên căn.

## 🚀 Tính năng nổi bật

- Giao diện Dark Mode/Light Mode thiết kế tỉ mỉ.
- Tích hợp **Pre-Seed Pitch Deck** nội bộ của Roomio tại đường dẫn riêng lẻ: `/pitch-investor-rm-2026x`. (Được cấu hình `noindex` để bảo mật thông tin).
- Tối ưu hóa SEO & Mobile Responsive.
- Hệ thống đa ngôn ngữ (i18n) với các route được tối ưu (en, ar).

## 💻 Chạy dự án (Local Development)

```sh
# 1. Cài đặt các dependencies
npm install

# 2. Khởi động server (Mặc định chạy ở cổng 4321)
npm run dev
```

## 📦 Build & Deploy

```sh
npm run build
npm run preview
```
